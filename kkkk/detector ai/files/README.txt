========================================
  Bhagyalaxmi Object Detector
  README - How to Use
========================================

REQUIREMENTS
------------
- Windows 10 or 11
- Python 3.8 or higher (free from python.org)
- Laptop / USB webcam
- Internet connection (first run only, to download model)

HOW TO RUN
----------
1. Make sure Python is installed.
   Download from: https://www.python.org/downloads/
   IMPORTANT: During install, tick "Add Python to PATH"

2. Double-click "RUN_THIS.bat"
   - It will auto-install OpenCV and YOLOv8
   - Then open your camera window

3. On first run it downloads a small AI model (~6 MB).
   After that it works offline.

4. Press Q in the camera window to quit.

WHAT IT DETECTS
---------------
YOLOv8 can detect 80 everyday objects including:
  person, chair, bottle, cup, laptop, phone,
  book, clock, tv, keyboard, mouse, door,
  backpack, umbrella, and many more.

TROUBLESHOOTING
---------------
- "Cannot open webcam" → Make sure no other app is using the camera
- Slow detection → Normal on older laptops; it will still work
- Python not found → Re-install Python and tick "Add to PATH"
